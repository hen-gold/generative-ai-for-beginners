# Lesson 15: Retrieval Augmented Generation (RAG) and Vector Databases

**Type:** Build  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/15-rag-and-vector-databases)  
**Video:** [Watch on YouTube](https://aka.ms/gen-ai-lesson15-gh?WT.mc_id=academic-105485-koreyst)

## Overview

Learn to build RAG applications that combine LLMs with your own data sources, enabling accurate, up-to-date responses grounded in your documents.

## Learning Objectives

- Understand RAG architecture
- Implement document retrieval
- Build RAG pipelines
- Integrate vector databases

## Key Components

1. **Document Processing**: Chunk and embed documents
2. **Vector Storage**: Store embeddings in vector DB
3. **Retrieval**: Find relevant documents
4. **Generation**: Generate answers using retrieved context

## RAG Benefits

- Reduces hallucinations
- Provides source citations
- Updates knowledge without retraining
- Domain-specific accuracy
