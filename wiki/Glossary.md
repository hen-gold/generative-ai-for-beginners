# Glossary of Generative AI Terms

A comprehensive glossary of key terms and concepts used throughout the course.

## A

**AI (Artificial Intelligence)**  
Computer systems that can perform tasks typically requiring human intelligence, such as visual perception, speech recognition, and decision-making.

**API (Application Programming Interface)**  
A set of protocols and tools for building software applications, allowing different software to communicate with each other.

**Attention Mechanism**  
A technique that allows models to focus on relevant parts of input data, crucial to the Transformer architecture.

**Azure OpenAI Service**  
Microsoft's cloud service providing access to OpenAI's models with enterprise-grade security and compliance.

## B

**BERT (Bidirectional Encoder Representations from Transformers)**  
A language model that reads text bidirectionally, useful for understanding context.

**Bias**  
Systematic errors in AI outputs, often reflecting biases in training data.

## C

**Chain-of-Thought (CoT)**  
A prompting technique that encourages the model to reason step-by-step.

**ChatGPT**  
OpenAI's conversational AI based on GPT models, optimized for dialogue.

**Context Window**  
The maximum amount of text (in tokens) a model can process at once.

**Completion**  
The text generated by a language model in response to a prompt.

## D

**DALL-E**  
OpenAI's image generation model that creates images from text descriptions.

**Deep Learning**  
A subset of machine learning using neural networks with multiple layers.

**Deterministic**  
Producing the same output given the same input (achieved with temperature=0).

## E

**Embedding**  
A numerical representation of text, images, or other data as vectors, capturing semantic meaning.

**Epoch**  
One complete pass through the entire training dataset during model training.

## F

**Few-Shot Learning**  
Teaching a model through a small number of examples in the prompt.

**Fine-Tuning**  
Training a pre-trained model on specific data to specialize it for particular tasks.

**Foundation Model**  
A large pre-trained model that can be adapted for various downstream tasks.

**Function Calling**  
Allowing LLMs to execute external functions or APIs.

## G

**Generative AI**  
AI systems capable of creating new content (text, images, code, etc.).

**GPT (Generative Pre-trained Transformer)**  
OpenAI's family of language models, including GPT-3.5 and GPT-4.

**Grounding**  
Connecting LLM outputs to factual sources to reduce hallucinations.

## H

**Hallucination**  
When a model generates false or nonsensical information presented as fact.

**Hugging Face**  
A platform for sharing and using open-source machine learning models.

**Hyperparameters**  
Settings that control model training and generation (e.g., temperature, learning rate).

## I

**Inference**  
Using a trained model to make predictions or generate outputs.

**Instruction Tuning**  
Training a model to better follow user instructions.

## L

**Large Language Model (LLM)**  
AI models trained on vast amounts of text data to understand and generate human language.

**Latency**  
The time delay between sending a request and receiving a response.

**LangChain**  
A framework for building applications with language models.

**LLMOps**  
Practices and tools for managing the lifecycle of LLM applications.

## M

**Max Tokens**  
The maximum number of tokens the model will generate in a response.

**Model**  
A trained AI system that can make predictions or generate outputs.

**Multi-Modal**  
AI systems that can process multiple types of input (text, images, audio).

## N

**Neural Network**  
A machine learning model inspired by biological neural networks in the brain.

**NLP (Natural Language Processing)**  
The field of AI focused on understanding and generating human language.

## O

**One-Shot Learning**  
Providing a single example in the prompt to guide the model.

**OpenAI**  
AI research company that created GPT models, DALL-E, and other generative AI systems.

## P

**Parameters**  
The learned weights in a neural network (e.g., GPT-4 has ~1.7 trillion parameters).

**Prompt**  
The input text given to a language model to generate a response.

**Prompt Engineering**  
The art and science of designing effective prompts to get desired outputs.

## R

**RAG (Retrieval Augmented Generation)**  
Combining information retrieval with generation to produce grounded, accurate responses.

**Reinforcement Learning from Human Feedback (RLHF)**  
Training technique using human feedback to improve model outputs.

**Role**  
In chat APIs: system, user, or assistant - defines the message sender.

## S

**Semantic Search**  
Searching based on meaning rather than exact keyword matches.

**Small Language Model (SLM)**  
Smaller, more efficient language models (e.g., Phi, Mistral 7B).

**System Message**  
Instructions that set the behavior and personality of the AI assistant.

## T

**Temperature**  
A parameter (0-2) controlling randomness in generation. Lower = more deterministic, higher = more creative.

**Token**  
The basic unit of text processed by LLMs (roughly 3/4 of a word in English).

**Tokenizer**  
Converts text into tokens that the model can process.

**Top-K**  
Sampling from the top K most likely tokens.

**Top-P (Nucleus Sampling)**  
Sampling from the smallest set of tokens whose cumulative probability exceeds P.

**Transfer Learning**  
Using a model trained on one task as a starting point for a different task.

**Transformer**  
The neural network architecture underlying most modern LLMs, introduced in "Attention is All You Need" (2017).

## V

**Vector**  
A numerical array representing data in multi-dimensional space.

**Vector Database**  
A database optimized for storing and searching vector embeddings.

## Z

**Zero-Shot Learning**  
The model performing a task without any specific examples in the prompt.

## Quick Reference

### Model Sizes
- **Small**: 1-7B parameters
- **Medium**: 7-30B parameters  
- **Large**: 30-70B parameters
- **Very Large**: 70B+ parameters

### Temperature Guide
- **0.0-0.3**: Factual, consistent
- **0.5-0.7**: Balanced
- **0.8-1.0**: Creative
- **1.0+**: Very creative, unpredictable

### Token Estimates
- 1 token ≈ 4 characters in English
- 1 token ≈ ¾ of a word
- 100 tokens ≈ 75 words
- 1000 tokens ≈ 750 words
