# Lesson 19: Building with Small Language Models (SLMs)

**Type:** Learn  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/19-slm)

## Overview

Discover the benefits of Small Language Models (SLMs) and when to use them over larger models.

## Learning Objectives

- Understand SLM advantages
- Compare SLMs to large models
- Select appropriate model sizes
- Optimize for edge deployment

## Benefits of SLMs

- **Cost-effective**: Lower API costs
- **Faster**: Reduced latency
- **Privacy**: Can run on-device
- **Efficiency**: Lower resource requirements

## Popular SLMs

- **Phi-2/Phi-3**: Microsoft's efficient models
- **Gemini Nano**: Google's on-device model
- **Mistral 7B**: Strong performance, smaller size

## Use Cases

- Mobile applications
- Edge devices
- Cost-sensitive applications
- Privacy-critical scenarios
- Real-time responses
