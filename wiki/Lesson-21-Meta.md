# Lesson 21: Working with Meta Models

**Type:** Build  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/21-meta)

## Overview

Explore Meta's LLaMA family of models and learn to use them in your applications.

## Learning Objectives

- Use LLaMA 2 and LLaMA 3 models
- Deploy Meta models
- Fine-tune for specific tasks
- Build with open source foundations

## LLaMA Models

- **LLaMA 2**: 7B, 13B, 70B variants
- **LLaMA 3**: Latest generation
- **Code LLaMA**: Specialized for coding

## Advantages

- Fully open source
- Strong performance
- Research-friendly license
- Active community

## Deployment Options

- Local deployment
- Cloud hosting
- Hugging Face integration
- Azure ML
