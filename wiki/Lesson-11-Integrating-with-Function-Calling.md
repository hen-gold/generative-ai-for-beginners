# Lesson 11: Integrating External Applications with Function Calling

**Type:** Build  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/11-integrating-with-function-calling)  
**Video:** [Watch on YouTube](https://aka.ms/gen-ai-lesson11-gh?WT.mc_id=academic-105485-koreyst)

## Overview

Learn to extend LLM capabilities by integrating external APIs and functions, enabling your AI to take actions and retrieve real-time data.

## Learning Objectives

- Understand function calling concepts
- Define function schemas
- Implement function handlers
- Build applications with external integrations

## Use Cases

- Weather data retrieval
- Database queries
- API integrations
- Real-time information access
