# Lesson 20: Working with Mistral Models

**Type:** Build  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/20-mistral)

## Overview

Learn to work with Mistral AI's powerful open-source models, including deployment and optimization.

## Learning Objectives

- Use Mistral AI models
- Deploy Mistral on different platforms
- Optimize Mistral performance
- Compare with other models

## Mistral Models

- **Mistral 7B**: Efficient base model
- **Mixtral 8x7B**: Mixture of experts model
- **Mistral Large**: Most capable model

## Key Features

- Strong multilingual support
- Efficient inference
- Open weights (some models)
- Commercial usage allowed
