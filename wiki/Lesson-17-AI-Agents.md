# Lesson 17: AI Agents

**Type:** Build  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/17-ai-agents)  
**Video:** [Watch on YouTube](https://aka.ms/gen-ai-lesson17-gh?WT.mc_id=academic-105485-koreyst)

## Overview

Build autonomous AI agents that can reason, plan, and take actions to accomplish complex tasks.

## Learning Objectives

- Understand AI agent architecture
- Implement agent frameworks
- Build multi-agent systems
- Handle agent orchestration

## Agent Capabilities

- **Reasoning**: Analyze situations and make decisions
- **Planning**: Break down complex tasks
- **Tool Use**: Execute functions and APIs
- **Memory**: Remember context and learnings

## Agent Frameworks

- **LangChain**: Popular Python framework
- **AutoGPT**: Autonomous task completion
- **BabyAGI**: Task-driven autonomous agent
- **Semantic Kernel**: Microsoft's agent framework

## Use Cases

- Research assistants
- Automated workflows
- Customer service bots
- Code generation and debugging
