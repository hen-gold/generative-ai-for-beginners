# Lesson 08: Building Search Applications with Vector Databases

**Type:** Build  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/08-building-search-applications)  
**Video:** [Watch on YouTube](https://aka.ms/gen-ai-lesson8-gh?WT.mc_id=academic-105485-koreyst)

## Overview

Build semantic search applications using embeddings and vector databases. Learn how to search by meaning, not just keywords.

## Learning Objectives

- Understand embeddings and vector representations
- Implement semantic search
- Work with vector databases
- Build a search application

## Key Concepts

### Embeddings
Convert text into numerical vectors that capture semantic meaning.

### Vector Databases
Store and efficiently search through embeddings.

### Semantic Search
Find similar content based on meaning, not just exact matches.
