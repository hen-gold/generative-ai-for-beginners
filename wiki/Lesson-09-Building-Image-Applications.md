# Lesson 09: Building Image Generation Applications

**Type:** Build  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/09-building-image-applications)  
**Video:** [Watch on YouTube](https://aka.ms/gen-ai-lesson9-gh?WT.mc_id=academic-105485-koreyst)

## Overview

Learn to build image generation applications using DALL-E and other image generation models.

## Learning Objectives

- Use DALL-E API for image generation
- Craft effective image prompts
- Handle image variations and edits
- Build an image generation app

## Key Features

- Text-to-image generation
- Image variations
- Image editing and inpainting
- Prompt engineering for images
