# Lesson 16: Open Source Models and Hugging Face

**Type:** Build  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/16-open-source-models)  
**Video:** [Watch on YouTube](https://aka.ms/gen-ai-lesson16-gh?WT.mc_id=academic-105485-koreyst)

## Overview

Explore open source LLMs and learn to use Hugging Face for model discovery, deployment, and fine-tuning.

## Learning Objectives

- Discover open source models
- Use Hugging Face Transformers
- Deploy open source models
- Compare with commercial models

## Popular Open Source Models

- **LLaMA 2**: Meta's foundation model
- **Mistral**: High-performance open model
- **Falcon**: Strong multilingual capabilities
- **Phi**: Microsoft's small language models

## Hugging Face Ecosystem

- Model Hub: Discover thousands of models
- Transformers: Easy model integration
- Datasets: Access training data
- Spaces: Deploy demos
