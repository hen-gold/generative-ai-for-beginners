# Generative AI for Beginners - Wiki

Welcome to the **Generative AI for Beginners** course wiki! This comprehensive guide provides easy navigation through all 21 lessons of the course.

## 🎯 About This Course

This course teaches everything you need to know to start building Generative AI applications. Each lesson covers a specific topic with hands-on examples in Python and TypeScript.

## 🚀 Quick Start

New to the course? Start here:

1. **[Course Setup](./Lesson-00-Course-Setup)** - Set up your development environment
2. **[Introduction to Generative AI](./Lesson-01-Introduction-to-GenAI)** - Learn the fundamentals
3. Browse through the [Full Course Curriculum](#course-curriculum) below
