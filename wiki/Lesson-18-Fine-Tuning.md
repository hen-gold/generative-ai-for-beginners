# Lesson 18: Fine-Tuning LLMs

**Type:** Learn  
**Full Lesson:** [View in Repository](https://github.com/microsoft/generative-ai-for-beginners/tree/main/18-fine-tuning)  
**Video:** [Watch on YouTube](https://aka.ms/gen-ai-lesson18-gh?WT.mc_id=academic-105485-koreyst)

## Overview

Learn when and how to fine-tune Large Language Models for your specific use case.

## Learning Objectives

- Understand fine-tuning concepts
- Know when to fine-tune vs. prompt engineering
- Prepare training data
- Evaluate fine-tuned models

## When to Fine-Tune

✅ Need consistent output format  
✅ Domain-specific language/jargon  
✅ Have sufficient training data (100+ examples)  
✅ Prompt engineering insufficient  

❌ Simple tasks (use prompting)  
❌ Limited data  
❌ Frequently changing requirements  

## Fine-Tuning Process

1. **Data Collection**: Gather quality examples
2. **Data Preparation**: Format for training
3. **Training**: Fine-tune the model
4. **Evaluation**: Test performance
5. **Deployment**: Use fine-tuned model

## Cost Considerations

- Training costs
- Inference costs (usually similar to base model)
- Data preparation time
- Ongoing maintenance
